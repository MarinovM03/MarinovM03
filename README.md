## 🚀 Featured Project

### ₿ Bitcoin Learning Hub

A full-stack educational platform for learning about Bitcoin through articles, community-created content, interactive learning paths, quizzes, live market information, and practical Bitcoin tools.

Built with **React**, **TypeScript**, **Node.js**, **Express**, and **MongoDB**.

- Authentication, ownership rules, and role-based administration
- Learning paths, quizzes, certifications, articles, and glossary content
- Live market data and interactive Bitcoin tools
- Search, bookmarks, comments, drafts, profiles, and moderation
- Security hardening, rate limiting, sanitization, and responsive design

[![View Repository](https://img.shields.io/badge/View_Bitcoin_Learning_Hub-F7931A?style=for-the-badge&logo=bitcoin&logoColor=white)](https://github.com/MarinovM03/bitcoin-learning-hub)
